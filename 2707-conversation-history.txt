● 1. Claude Code hiện hỗ trợ những cách nào để nối Google Sheets

  a) Connector "Google Drive" cấp tài khoản (đã có sẵn trong phiên này)
  Tôi thấy phiên hiện tại đã có sẵn các tool mcp__claude_ai_Google_Drive__*
  (search_files, read_file_content, download_file_content, get_file_metadata,
  list_recent_files...). Đây là connector Google Drive gắn với tài khoản
  claude.ai/Claude Desktop đã đăng nhập, không phải thứ bạn cấu hình trong 
  project. Đã kiểm tra kỹ khả năng đọc Sheet của nó:

  - read_file_content với file application/vnd.google-apps.spreadsheet → trả về
  "natural language representation", không đảm bảo cấu trúc bảng, và "có thể 
  không đầy đủ với file lớn" — không đáng tin cho việc tính KPI chính xác.
  - download_file_content với exportMimeType=text/csv → export CSV, nhưng giới
  hạn của Google Drive export API là chỉ lấy được tab/sheet đầu tiên, không chọn
  được range hay tab cụ thể.
  - Gắn với tài khoản Google cá nhân đã kết nối, không cấu hình được qua file 
  trong repo → người khác dùng lại project sẽ không tái tạo được, không phải
  "Tool" theo đúng nghĩa hạ tầng dự án.

  → Dùng được cho việc "liếc nhanh" nhưng không đủ tin cậy làm nguồn dữ liệu
  thật cho phân tích KPI của nhiều Skill.

  b) MCP (Model Context Protocol) — cơ chế chính thức của Claude Code
  Claude Code hỗ trợ chính thức việc thêm tool mới qua MCP server, cấu hình qua
  claude mcp add hoặc file .mcp.json (project scope, commit được vào repo để cả
  team dùng chung). Đây là cách "đúng chuẩn" để cấp cho Claude một tool thật, có
  schema rõ ràng, không phụ thuộc tài khoản cá nhân.

  c) Gọi thẳng Google Sheets API qua script (Bash), không qua MCP
  Vẫn khả thi (viết 1 script Python/Node dùng Service Account, Claude gọi qua
  Bash), nhưng kém "tool-like": không có schema input/output, các Skill phải
  biết đúng cú pháp lệnh, dễ lỗi khi tái sử dụng.

  2. Phương án chọn

  → MCP server riêng cho Google Sheets, backend là Google Sheets API v4, xác 
  thực bằng Service Account (read-only).

  Lý do:
  - Là cơ chế mở rộng chính thức của Claude Code, cấu hình qua .mcp.json trong
  project → tái tạo được cho bất kỳ ai clone repo (chỉ cần tự tạo credentials
  riêng).
  - Service Account không cần luồng OAuth qua trình duyệt — chỉ cần share Sheet 
  với email service account như share với một người dùng bình thường (Viewer).
  - Trả dữ liệu dạng JSON có cấu trúc (headers + rows) theo đúng sheet/tab +
  range cụ thể → đúng nhu cầu "các Skill khác dùng lại được".
  - Đây là dữ liệu thật 100%, không mô phỏng, không phụ thuộc tài khoản cá nhân
  của ai.

  3. Cấu trúc Tool dự kiến (sẽ tạo sau khi bạn xác nhận)

  mcp-servers/
  └── google-sheets/
      ├── package.json                    # hoặc requirements.txt nếu chọn
  Python
      ├── src/index.ts                    # hoặc main.py — MCP server
      ├── credentials/service-account.json  # KHÔNG commit, chỉ máy local
      ├── .env.example
      └── README.md
  .mcp.json           # đăng ký server "google-sheets" với Claude Code (project
  scope)
  .gitignore           # thêm credentials/*.json

  Tools mà server sẽ expose:
  - list_sheet_tabs(spreadsheetId) → danh sách tên tab trong file
  - read_sheet(spreadsheetId, range?) → { headers: [...], rows: [[...]] } — dữ
  liệu bảng thật
  - get_spreadsheet_metadata(spreadsheetId) → tiêu đề, danh sách tab, kích thước

  4. Các bước thiết lập thật (Google Cloud + Claude Code)

  1. Tạo/chọn Google Cloud Project tại console.cloud.google.com.
  2. Bật API: APIs & Services → Enable APIs → tìm "Google Sheets API" → Enable.
  3. Tạo Service Account: IAM & Admin → Service Accounts → Create → ví dụ tên
  sheets-reader.
  4. Tạo Key: chọn service account → Keys → Add Key → JSON → tải file .json (đây
  là credentials).
  5. Lấy email service account (dạng xxx@xxx.iam.gserviceaccount.com, có trong
  file JSON).
  6. Chia sẻ Google Sheet thật: mở Sheet → Share → dán email service account →
  quyền Viewer (đủ vì chưa cần ghi).
  7. Lưu file JSON vào mcp-servers/google-sheets/credentials/, thêm vào
  .gitignore (không commit bí mật).
  8. Cài dependencies cho server, đăng ký với Claude Code (claude mcp add hoặc
  sửa .mcp.json), trỏ biến môi trường tới file credentials.
  9. Reload Claude Code, kiểm tra claude mcp list thấy server google-sheets
  connected.

  5. Ví dụ dùng thật (thực hiện sau khi cấu hình xong, cần bạn đưa 1 Sheet ID 
  thật đã share)

  Đọc Google Sheet (read_sheet) → Hiển thị bảng markdown → Skill
  google-sheet-reader tóm tắt KPI (theo docs/metrics-guide.md) → Phân tích & đề
  xuất theo template có sẵn — toàn bộ dựa trên dữ liệu thật lấy được.
