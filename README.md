# Marketing Workspace

Đây là workspace Claude Code phục vụ cho công việc **Digital Marketing** — nơi tổ chức các quy trình làm việc, tài liệu và kết quả đầu ra liên quan đến marketing, được hỗ trợ bởi Claude Code.

## Mục đích sử dụng

- Là không gian làm việc trung tâm cho các tác vụ Digital Marketing (nội dung, chiến dịch, phân tích, v.v.) khi sử dụng Claude Code.
- Chứa các **Skills** tuỳ chỉnh (trong `.claude/skills/`) để mở rộng khả năng của Claude Code cho các quy trình marketing cụ thể.
- Lưu trữ các **kết quả đầu ra** (trong `outputs/`) được tạo ra trong quá trình làm việc.

## Cấu trúc thư mục

```
marketing-workspace/
├── .claude/
│   └── skills/      # Các Skill tuỳ chỉnh cho Claude Code
├── outputs/         # Kết quả đầu ra của các tác vụ
├── README.md        # Tài liệu giới thiệu workspace
└── .gitignore        # Danh sách file/thư mục bỏ qua khi dùng Git
```

## Trạng thái hiện tại

Workspace mới được khởi tạo, chưa có Skill nào được thêm vào.
